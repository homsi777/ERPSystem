
واجهة أمامية عربية متكاملة لنظام **ERP PRO**، مخصصة لإدارة تجارة الأقمشة، الأثواب، المستودعات، الاستيراد، المبيعات، المشتريات، المحاسبة والعمليات المالية.

تم تصميم المشروع ليكون نموذجًا احترافيًا لنظام ERP حديث، مع دعم كامل للغة العربية واتجاه **RTL**، وتجربة استخدام مناسبة لأجهزة سطح المكتب والشاشات الكبيرة.

## تشغيل المشروع محليًا

تأكد من تثبيت Node.js، ثم نفذ:

```bash
git clone <repository-url>
cd <project-folder>
npm install
npm run dev

بعد التشغيل، افتح الرابط المحلي الذي يظهر في الطرفية.

بناء نسخة الإنتاج
npm run build

يتم إنشاء ملفات الإنتاج داخل مجلد البناء الخاص بالمشروع، وغالبًا يكون:

dist/
